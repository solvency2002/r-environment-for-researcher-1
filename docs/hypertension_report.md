# 高血圧症シミュレーションデータ解析報告書

## 概要

本レポートは、100例の仮想的な高血圧症患者データを対象としたロジスティック回帰分析の結果をまとめたものです。年齢、BMI、および喫煙習慣が高血圧の有無に与える影響を検討しました。

## 1. 記述統計

対象者100名のうち、高血圧（Yes）は 49名、非高血圧（No）は 51名でした。

| 項目 | 高血圧 (n=49) | 非高血圧 (n=51) |
| :--- | :--- | :--- |
| **年齢 (平均)** | 57.8 歳 | 51.0 歳 |
| **BMI (平均)** | 25.1 kg/m² | 22.8 kg/m² |
| **喫煙者 (n)** | 16 名 (32.7%) | 10 名 (19.6%) |

## 2. ロジスティック回帰分析結果

高血圧の有無を従属変数とするロジスティック回帰分析の結果を以下に示します。

| 変数 | オッズ比 (OR) | 95% 信頼区間 (CI) | p値 |
| :--- | :--- | :--- | :--- |
| **年齢** | 1.07 | [1.03, 1.13] | 0.004 ** |
| **BMI** | 1.13 | [1.02, 1.27] | 0.031 * |
| **喫煙 (Yes)** | 1.71 | [0.63, 4.77] | 0.294 |

(\*: p < 0.05, \*\*: p < 0.01)

## 3. 考察

解析の結果、**年齢**と**BMI**において統計的に有意な高血圧リスクの増大が認められました。

- 年齢が1歳上昇するごとに、高血圧のリスクは約7%増加します (OR 1.07)。
- BMIが1上昇するごとに、高血圧のリスクは約13%増加します (OR 1.13)。
- 喫煙については本データセットでは統計的に有意な差は認められませんでした (OR 1.71, p=0.29)。

## 結論

本シミュレーションにおいては、年齢とBMIが高血圧の独立したリスク因子であることが示唆されました。100例という小規模なサンプルサイズではありますが、明確な傾向が確認できました。
